# 🎬 ScriptD AI

**ScriptD AI** is an intelligent assistant built specifically for Indian content creators (YouTubers, Reel Makers, Documentarians, and Storytellers). It bridges the gap between writing a script and creating the final video.

## 🚀 The Problem We Solve
Creators often struggle with:
1. Finding the right topic and format (Comedy vs. Documentary).
2. Writing scripts that retain audience attention.
3. Matching their script with the right visuals (images/videos).
4. Optimizing titles and descriptions for platform algorithms.

## ✨ Key Features

### 🆓 Normal (Free) Plan:
- **Deep Research:** AI researches multiple sources to suggest the best format and gives percentage-based success predictions.
- **High-Quality Script:** Story-driven scripts with built-in retention hooks.
- **Visualization Front:** Scene-by-scene visual descriptions for the creator to imagine.
- **Basic Metadata:** Platform-ready titles and descriptions.

### 👑 Premium Plan:
- **Everything in Normal.**
- **Scene-wise Image Generation:** The AI asks clarifying questions and generates exact images based on the script (e.g., "A sad child holding a paper with 90% written on it").
- **Multi-platform Optimization:** Advanced A/B testing titles and algorithm-based push strategies for YouTube, Instagram, and Facebook.
- *(Coming Soon: Voiceover, Sound Effects, and Video Generation)*

## 🛠️ Tech Stack
- **Frontend:** Flutter (Mobile App)
- **Backend:** Node.js / Python (FastAPI)
- **AI Engine:** Claude API (Scripting & Research)
- **Image Engine:** Flux / Stability AI (for Premium Visuals)
